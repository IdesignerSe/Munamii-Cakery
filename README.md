# 🍰 Munamii Cakery — Static Website Project

A simple, responsive 4‑page website built for **Munamii Cakery**, a cupcake and wedding‑cake business transitioning from Instagram to a more formal online presence.  
This project follows the full specifications provided in the assignment PDF.

---

## 📌 Project Overview

The goal of this project is to create a small, static website that showcases the bakery’s products and provides essential business information.  
The site is designed to work on both **mobile** and **desktop** without requiring JavaScript or complex navigation.

---

## ✅ Features Implemented

### **✔ Required Pages**
- **Home** — Welcome message and introduction  
- **About** — Bakery story and background  
- **Products** — Cupcakes + Wedding Cakes (8 items each)  
- **Contact** — Delivery, pickup, and business hours  

### **✔ Layout & Structure**
- Shared **header** and **footer** across all pages  
- Simple responsive layout using CSS Grid  
- Clean, pastel color palette  
- No emojis (per project requirement)

### **✔ Product Requirements**
- 8 Cupcakes (image + title + price)  
- 8 Wedding Cakes (image + title + price)  
- Organized into two categories on the Products page  

### **✔ Footer Links**
- Instagram  
- Facebook  
- Email link  

---

## 🎨 Technologies Used

- **HTML5**
- **CSS3**
- **Google Fonts (optional to add)**
- **Unsplash / Instagram images**

No JavaScript was required for this project.

---

## 📱 Responsiveness

The layout uses:

- `display: grid`
- `auto-fit` and `minmax()`  
- Flexible images and spacing  

This ensures the site works on both **phones** and **computers**, as required.

---

## 📝 Optional Features (Not Implemented Yet)

These were optional in the assignment and can be added later:

- Contact form that sends an email  
- Email subscription section (e.g., MailChimp integration)

---

## 🚀 How to Run the Project

1. Download or clone the repository  
2. Open the project folder in VS Code  
3. Open `index.html` in your browser  
   - or use the **Live Server** extension
